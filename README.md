🛒 SmartMart — Online Supermarket Management System | C++

I developed a console-based Online Supermarket Management System using C++, designed to simulate the core workflow of a modern online grocery store.

✨ Key Features:
🥦 Multiple product categories and product management
🔎 Product search by ID
🛒 Add and remove products from the shopping cart
📦 Real-time stock management
💰 Automatic subtotal, discounts, and delivery fees
💳 Checkout and order confirmation
🔢 Unique Order ID generation
📋 Order history and order status
⚠️ Stock availability validation and low-stock reporting
🚚 Delivery area and estimated delivery information

🛠️ Skills & Concepts:
C++ | Arrays | Loops | Conditions | Strings | Data Management | Business Logic | Problem Solving | User Input

💡 This project helped me practice building a complete e-commerce workflow and translating real-world supermarket operations into a functional C++ application, while strengthening my programming fundamentals before moving into OOP.
